# Iron Core: AI Commander

Браузерная RTS по брифу «Warcraft-like игра с ИИ-агентом, управляющим боевыми роботами, и голосовым управлением».
Игрок не ведёт каждого робота: он ставит задачи GenAI-агентам голосом или текстом. Агенты проектируют машины и планируют бой,
а игра считает физику, валидирует проекты и исполняет планы. Боты (инженер, тактик и вражеский генерал) думают **облачным LLM API**.

Стек: React 18 + TypeScript + Vite, Three.js (мультяшная изометрия), Tailwind, Web Speech API (ASR/TTS).

## Запуск

```bash
npm install
cp .env.example .env.local   # укажите LLM_PROXY_TARGET / LLM_API_KEY / LLM_MODEL
npm run dev
```

Откройте адрес из консоли Vite. На стартовом экране видно, к какой модели подключены боты.

### Готовая сборка из релиза

В релизе на GitHub лежит архив `iron-core-ai-rts-v0.2.0-dist.zip` со статической сборкой. Её можно отдать любым
статическим сервером, например `npx serve dist`. Серверного прокси `/api/llm` в статической сборке нет, поэтому LLM
подключается напрямую из браузера: ⚙ → провайдер, ключ и модель. Сервер модели должен разрешать CORS.

### Подключение LLM

Есть два способа, оба OpenAI-совместимые:

1. **Серверный прокси (рекомендуется).** Dev/preview-сервер Vite проксирует `/api/llm/*` на `LLM_PROXY_TARGET`
   и сам подставляет `LLM_API_KEY` из `.env.local`. Ключ не попадает в браузер. При первом запуске игра сама выбирает прокси,
   если он настроен.
   - Локальная модель (oMLX/vLLM/LM Studio): `LLM_PROXY_TARGET=http://127.0.0.1:8000/v1`, `LLM_MODEL=Qwen3.6-35B-A3B-UD-MLX-4bit`.
   - Облако (OpenRouter, Qwen): `LLM_PROXY_TARGET=https://openrouter.ai/api/v1`, `LLM_MODEL=qwen/qwen3-30b-a3b-instruct-2507`.
2. **Напрямую из браузера.** ⚙ → выберите провайдера (OpenRouter·Qwen, Alibaba DashScope, Groq, OpenAI, Gemini,
   Anthropic, свой OpenAI-совместимый), вставьте ключ, загрузите список моделей и нажмите «Проверить подключение».
   Ключ хранится только в `localStorage` этого браузера.

Бриф советует быстрые недорогие модели семейства Qwen, поэтому по умолчанию стоит Qwen3 MoE. Для гибридных Qwen3 клиент
отключает скрытое «размышление» (`chat_template_kwargs.enable_thinking=false` / `enable_thinking` / `reasoning_effort`).
Иначе модель сжигает бюджет токенов и отвечает в разы медленнее. Без настроенного LLM агенты отвечают локальными
эвристиками, и UI помечает такие ответы как «локально».

## Как боты используют LLM

| Агент | Когда вызывается | Что возвращает | Что делает игра |
|---|---|---|---|
| **Болт**, агент производства | приказ игрока | конфигурация из каталога и/или производственные действия, компромисс, лимит стоимости | считает характеристики, проверяет слоты, массу, энергию, отдачу и лимит стоимости; при нарушении делает один раунд починки через LLM, затем локальную починку с объяснением; показывает «до/после» и ждёт «В серию / Отмена» |
| **Кобра**, агент управления | приказ игрока и **автономно** сразу по значимым событиям (тяжёлые потери, атака на базу или добычу, новая модель врага), не чаще раза в 8 с | план: стойка, дистанция, приоритет целей, порог отступления на ремонт, прикрытие добычи | игровой AI исполняет план между вызовами; план можно откатить или поправить вручную |
| **Генерал Ржавый**, AI-противник | полная сводка раз в ~30 с; быстрый пересмотр плана сразу по событиям боя, не чаще раза в 8 с | сводка: контр-конструкция, план, экономика, язвительная реплика (перехват); пересмотр: только план и короткая реплика | валидирует и применяет; при недоступности LLM работает классический AI на правилах |

Контекст каждого вызова короткий (бриф §10): роль, актуальные инструкции игрока, допустимые действия, компактная сводка
армии и экономики, замеченные модели врага, 5 последних существенных событий и каталог деталей. Полная история и
покадровая телеметрия не передаются. Модель не назначает бонусов и не управляет движением роботов.

Реакция на бой. События одной атаки собираются ~1 с и уходят одним вызовом. Пока вызов в работе, новые события ждут его
и отправляются сразу после ответа. Пересмотр командира по событию короткий: без каталога и экономики, ответ ~100 токенов,
поэтому даже медленная локальная модель отвечает за секунды. Пока модель думает, игровой AI реагирует сам: если базу
обстреливают, машины рядом с домом (в том числе ждущие на точке сбора) идут на нападающего.

## Режим «ИИ против ИИ»

Вторая кнопка на стартовом экране запускает матч без участия человека. За бирюзовых играет Командор Бирюзов, за
оранжевых — Генерал Ржавый. Оба — LLM-командиры с одинаковыми правилами: раз в ~30 с проектируют машины из каталога,
задают план армии и экономику и переругиваются в эфире, а по событиям боя быстро пересматривают план. Без настроенного LLM оба переходят на локальные правила.

- Командиры обращаются к модели по очереди, а не одновременно: локальный сервер обрабатывает запросы последовательно.
  Первым ходит тот, кто дольше ждал, так что предел частоты решений одинаков для обоих.
- Перед стартом можно дать Командору Бирюзову свои указания, до 500 символов. Они попадают в его системный промпт и
  повторяются в конце каждой сводки, так модель следует им заметно надёжнее. Это касается и полных сводок, и быстрых
  пересмотров плана. Генерал Ржавый указаний не видит. Текст сохраняется в браузере, а панель зрителя показывает
  действующие указания.
- Панель зрителя показывает обе стороны: реплики, источник решения (LLM или правила), серийную модель, план, армию,
  добытчиков, металл и штаб. Есть скорость ×1/×2/×4, кнопка «В меню» и итоги матча со сравнением сторон.
- Режим ничего не списывает с баланса AI-монет: это демонстрация. Расход токенов виден в панели монет.

## AI-монеты (бриф §10)

- Отдельный тестовый баланс (не металл и не энергия) и лимит расходов на матч (⚙ или панель монет).
- Детализация по четырём сервисам: агент производства, агенты управления, распознавание речи (ASR), синтез речи (TTS).
  AI-противник учитывается отдельной строкой и по умолчанию не списывается; его можно включить в тариф.
- Учитываются входные/выходные токены, секунды ASR/TTS, число вызовов, ошибки и задержки.
- Списание идемпотентно: ошибки и технические повторы не оплачиваются дважды.
- Игра заранее предупреждает, когда монеты на исходе. После исчерпания армия продолжает последний допустимый план
  обычным игровым AI.
- Частота автономных AI-решений одинакова для обоих участников: больший баланс не даёт более частого управления.

## Управление

Камера: перетаскивание мышью, колесо для масштаба, WASD или стрелки, клик по мини-карте. Приказы — микрофон или текст.
Голосом можно сказать «в серию», «испытай» или «отмена» для текущего проекта.

**Испытание конструкции до производства** (открытое решение брифа §9): кнопка «Испытать» в панели конструктора прогоняет
безголовые бои 4×4 нового проекта против модели врага, замеченной разведкой (без разведданных — против базовой модели).
Бои идут на трёх дистанциях с разными флангами на реальном боевом коде: броня, нагрев, развёртывание, отдача.
Результат: доля побед, длительность боя, оставшаяся прочность. Для сравнения показываются текущая серия и вариант
«равный бюджет», то есть несколько дешёвых машин против одной дорогой. Испытание бесплатно по AI-монетам: это игровая
симуляция, а не inference. Зато вердикт приходит через 5 секунд игрового времени, так что игрок выбирает между темпом
и информацией, а «В серию» можно нажать, не дожидаясь стенда. Добытчики, электростанции, второй завод и размер
партии задаются в панели «Производство» или через приказ инженеру.

## Покрытие брифа

| Раздел | Реализация |
|---|---|
| 1–2. Концепция и цикл | добыча → партия → столкновение → приказ агенту → новая партия; изменения идут только в следующие партии |
| 3. Экономика | металл с площадок и обломков; компоненты из металла (фабрикатор штаба); энергосеть базы ограничивает заводы, добычу, фабрикатор и ремонт; безопасные и центральные месторождения |
| 4. Ограничения робота | масса и разгон, бортовая энергия, слоты (объём), нагрев и перегрев, устойчивость к отдаче, развёртывание осадных орудий, цена и время сборки |
| 5. GenAI-агенты | конструктор с подтверждением, сравнением, компромиссом и уточнением; тактические агенты; текст как альтернатива голосу |
| 6. Бой и победа | волны «стенка на стенку», роли (артиллерия держится за линией, быстрые обходят и бьют добычу), турель штаба; победа — уничтожение командного центра |
| 7. Визуал и UI | мультяшная изометрия на ровном песке, бирюза против оранжевого, видимые модули на моделях, ресурсы и мощность, мини-карта, очереди заводов, панель конструктора с портретом, микрофоном, распознанной фразой, превью и полосами «до/после» |
| 8. Прототип | одна карта, две базы, игрок против AI, лёгкое/среднее/тяжёлое шасси, 3 брони, ближнее и дальнее оружие, 2 привода |
| 10. Монетизация | см. «AI-монеты» |

Открытые решения брифа, принятые по умолчанию: уничтожение (а не захват) базы; размер партии 1–5 (по умолчанию 3);
AI-противник не входит в тариф игрока; автономные пересмотры сразу по событию боя, но не чаще раза в 8 с на сторону; испытание конструкции до производства
доступно и стоит 5 с игрового времени.

## iOS-приложение (модель на устройстве)

В `ios/` лежит приложение для iPhone и iPad. Внутри та же игра в WKWebView, но агенты думают **моделью Apple
на устройстве** (фреймворк Foundation Models, Apple Intelligence, Neural Engine): без сети, ключей и AI-трафика.

```bash
npm run build:ios                 # собрать игру в ios/Web (фиксированная ширина раскладки, без веб-шрифтов)
open ios/IronCore.xcodeproj       # Xcode 26+, схема IronCore; для iPhone укажите свою команду подписи
```

- **Требования.** iOS 26+, устройство с Apple Intelligence (iPhone 15 Pro и новее), Apple Intelligence включена.
  На других устройствах игра работает, а агенты переходят на локальные правила.
- **Русский язык.** Модель Apple не поддерживает русский. Для неё агенты получают английские промпты
  (`src/ai/promptsEn.ts`). Русские фрагменты — приказ, события, названия моделей, указания штаба — переводит на
  английский Apple Translation на устройстве. Поля ответа, которые видит игрок (реплика, компромисс, насмешка,
  суть плана, имя модели), переводятся обратно на русский. Языки система предлагает скачать при первом запуске.
  Без перевода промпты уходят как есть, а ответы остаются на английском.
- **Мост.** `window.webkit.messageHandlers.ironcoreLLM` (`ios/IronCore/OnDeviceBridge.swift` ↔
  `src/ai/llm/nativeBridge.ts`): `status`, `generate`, `translate`. Запросы к модели идут по одному, окно
  контекста — 4096 токенов.
- **Экран.** Ландшафт, вне зоны Dynamic Island. На низких экранах «Производство» и «План армии» свёрнуты
  до сводки и раскрываются по нажатию.
- **Симулятор.** Модель в симуляторе берётся с Mac: нужна включённая Apple Intelligence на самом Mac. Перевод в
  симуляторе не работает (`unsupportedLanguagePairing`). Отладочная сборка принимает аргументы запуска
  `-autotest` (короткий матч «ИИ против ИИ» на модели устройства с отчётом в консоль) и `-autoplay`:

```bash
xcrun simctl launch --console-pty booted com.ironcore.aicommander -autotest
```

## Код

```
src/ai/llm/LLMClient.ts      единый клиент LLM: OpenAI-совместимые API, Anthropic, прокси; таймауты, повторы, JSON
src/ai/AIDirector.ts         оркестрация агентов: триггеры, лимиты частоты, биллинг, валидация, откат на эвристики
src/ai/prompts.ts            роли и компактный контекст агентов
src/ai/promptsEn.ts          те же промпты на английском для модели на устройстве (русское — через перевод)
src/ai/llm/nativeBridge.ts   мост к модели Apple и переводу в iOS-приложении
src/ai/AIBilling.ts          AI-монеты, детализация по сервисам, лимит матча, единый предел частоты
src/ai/fallbacks.ts          локальные эвристики (без облака)
src/engine/GameState.ts      симуляция: экономика, производство, бой по плану, события
src/engine/RobotBuilder.ts   расчёт характеристик, валидация и починка проектов, сравнение «до/после»
src/engine/DesignTrial.ts    испытательный стенд: бои на арене с детерминированным seed
src/rendering/*              Three.js: изометрическая камера, toon-модели роботов и зданий, эффекты
src/game/GameController.ts   связка цикла игры, агентов, рендера, голоса и UI
src/components/*             HUD, панель конструктора, план армии, монеты, настройки
vite.config.ts               dev/preview-прокси /api/llm, сборка для iOS (--mode ios)
ios/IronCore/                SwiftUI-приложение: WKWebView, схема ironcore://, Foundation Models, Translation
```
